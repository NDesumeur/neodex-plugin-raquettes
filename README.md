# Raquettes

Un duel de raquettes contre l'ordinateur, sur un terrain de nuit. Le premier à 7 points gagne ; la balle accélère à chaque échange.

Ta raquette est à gauche. Renvoie la balle sans la laisser passer ; l'ordinateur prévoit les rebonds, plus ou moins bien selon son niveau. Le premier à 7 points gagne.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Raquettes → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
